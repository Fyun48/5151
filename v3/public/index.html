不離開這一頁。Webhook 與郵件是選用；預設用站內與系統推播。

我們特別推薦 Discord：免費、不用架伺服器，把 Webhook 貼上就能收到特別關注更新。其它相容 Discord 格式的 Webhook 也可以。

  1. 申請 Discord 帳號，並建立一個只給自己看的伺服器。
  2. 伺服器設定 → 整合 → Webhooks → 新增 Webhook，選一個頻道。
  3. 複製 Webhook 網址（會像 https://discord.com/api/webhooks/…）。
  4. 貼到下面並儲存。變更通知預設只會推「特別關注」的物件。

此通知預設只會訊息已是特別關注之物件。要改事件種類請切到「通知種類」。

這組 SMTP 只寄物件／屋源提醒到你註冊的信箱，請用你自己的帳號寄給自己。註冊歡迎、忘記密碼、變更密碼、贊助通知由站方管理員 SMTP 寄出，不會用這裡的密碼。

可用代碼：{{event}}、{{title}}、{{price}}、{{facts}}、{{url}}、{{detail}}、{{email}}。

Gmail 不能用平常登入的密碼。請到 Google 帳戶 → 安全性 → 兩步驟驗證 → 應用程式密碼，產生 16 碼後填在這裡。
