## 修改

- 列表與統計在讀取完整候選欄位、計算通勤與條件前，先用現有 `source_key` 的縣市／行政區前綴排除已知外區資料。
- 未知、缺少或非標準前綴仍交由原本地址／標題判斷，避免丟失歷史資料。
- 同房源關係的兩側、當前會員手動合併的成員仍保留給主副卡判斷。
- 統計的行政區過濾提前；共用搜尋底庫的下架計數另外以 SQL 計算，保留既有範圍。
- 所有排序仍在完整符合集合上執行，再分頁。沒有新增回應截斷、資料表遷移或讀取時寫入。

## 樂屋正式機診斷

在 CASAOS 主機終端執行：

```sh
docker exec 591-tracker-v3 node src/diagnoseRakuya.js
```

此指令以唯讀方式讀取三站入庫數，僅向樂屋台北搜尋首頁發出一次 15 秒上限的公開請求，輸出 HTTP 狀態、解析結果與耗時。不入庫、不發通知、不重試驗證頁。
