# Evidence: Clipboard 讀取失敗 → Agent 卡在 Retry — 2026-09-22

環境：Synology NAS 上的 code-server 容器（`5151-code-server`、`db1fb2abe75e`），
code-server 4.138.0 / VS Code core 1.138.0，Cline extension 4.1.19，
對外 `https://cocodeco.reversalplay.me`（Cloudflare Tunnel + Cloudflare Access）。

根因（位置、非推測）：VS Code Web 的 `BrowserClipboardService.readText()`（workbench bundle
中 `d(20492,null)` 那段）在 `navigator.clipboard.readText()` 被 Chromium 拒絕時，
會回傳一個**只有真人按 `Retry`（`d(20494,null)`）或關掉 sticky toast 才會 resolve** 的 Promise。
await 它的呼叫端（終端機/編輯器貼上、Cline 擴充的 `env.clipboardReadText` RPC）就一起卡住。
修法：把該 catch 改成 fail-open（log warning + 立刻回 `""`）。
