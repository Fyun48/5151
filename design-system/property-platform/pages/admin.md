# Admin / 後台

覆寫範圍：`v3/public/admin.html`。僅管理員。

## Purpose

會員、SMTP、抓取與站務設定。資訊密度高於前台，但仍用同一套 token，不要另做深色炫光後台。

## Layout

- 表格與表單為主，不是 dashboard 行銷模組。
- 左側分類各自一頁：畫面說明（形象／宣告／許願房條件選單）、功能說明 Q&A、公告專區、贊助曝光（收款連結）、站內小廣告、系統信件、使用者回饋、站內 CRM。
- CRM 用表格＋表單，375px 改單欄並允許表格橫向捲動。關閉模組只停新處理，資料保留。錯誤摘要放表單頂端並移入焦點。使用者回饋可「開立 CRM 案件」，不必先有會員帳號。
- 破壞性操作（刪除會員等）必須有確認與權限檢查。
- 不要在後台放 Hero、玻璃擬態或裝飾插圖。

## Security

- 未授權必須被擋在 API 與頁面。
- 不在畫面或前端原始碼暴露 SMTP 密碼、VAPID 私鑰或其他密鑰。
