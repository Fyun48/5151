# 5151 v2 架構

線上正在跑的是 repo 根目錄的 v1（`src/` + `public/`，埠 5151，資料 `data/591.db`）。GitHub Action 也只同步這兩包到 CasaOS。這份 `v2/` 是複製後的新版，資料在 `data-v2/v2.db`，預設埠 5152，完成前不會取代線上版。

## 目標

- 591 列表／詳情／座標／路線：全站一份，依「覆蓋搜尋」抓，不跟會員人數等比放大。
- 設定檔、特別關注、已瀏覽、隱藏、通知：依帳號分開。
- 通知讀自己的庫再套個人條件；不要每個會員各打一次 591。

## 分階段

1. **現在：** 複製可跑的 v2、獨立資料庫、覆蓋搜尋純邏輯、個人資料表骨架。畫面上仍是單人（與 v1 相同行為），方便對照。
2. **接著：** 抓取改為 `crawl_covers`（縣市／行政區聯集 + 租金取寬），列表改讀共用 `listings` 再套個人 flags。
3. **然後：** 真正的會員表登入（不再共用一個 AUTH）、個人通知佇列、免責聲明頁。
4. **再來：** 贊助方案只影響間隔／覆蓋範圍等，不影響「這是不是免費系統」的條款。
5. **最後：** 你確認 v2 可取代後，再停 v1。在那之前不要改 root `src/`、`public/` 的部署路徑。

## 覆蓋抓取（為什麼 20 人不必打 20 次 591）

會員 A 在士林／北投抓 4 萬以內，會員 B 只要 2 萬 → B 是 A 的子集，只讀庫。同一縣市多個行政區會合成一組 591 搜尋。台北 + 新北大約就是 **2 個覆蓋任務**，不是 20 條爬蟲。

新縣市：有會員需要才加入覆蓋；不是每 5 分鐘全台全掃。
