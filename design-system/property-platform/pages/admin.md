# Admin / 後台

覆寫範圍：`v3/public/admin.html`、`v3/public/admin-ia.js`。僅管理員。

## Purpose

讓管理員看分類名稱就知道功能在哪，不必靠記憶。資訊密度高於前台，仍用同一套 token。

## Layout

- 桌面：固定左側可展開二級選單 + header 功能搜尋 + breadcrumb。
- 手機：左側改 drawer，不要橫向捲動 tab。
- 每一頁：標題、一句話說明、狀態、設定、操作、最近變更。
- 破壞性操作放 Danger Zone，與一般儲存分開。
- 不要在後台放 Hero、玻璃擬態或裝飾插圖。

## Information architecture

1. **總覽**：唯讀狀態，不啟動 crawler／geo／route／reconciliation。
2. **房源與資料**：房源來源、抓取範圍與排程（含全站間隔與確認已下架天數）、同房源判定、外部物件匯入、資料健康度。
3. **會員與權限**：會員管理、方案與限制、訪客權限、登入政策。
4. **站台內容**：品牌、理念、法律與個資、內容版本庫、Q&A、居住數據、許願房條件。
5. **通知與溝通**：系統公告、最新消息、郵件服務、信件範本。
6. **收益與曝光**：贊助連結、支持本站（總覽／前台呈現／方案／收款／紀錄／企業贊助／成本／感謝牆／顯示規則／稽核）、贊助活動、站內曝光。已停用功能折疊。支持本站預設旗標關閉；Preview 讀草稿。企業贊助必須標「贊助」，且不得進入 listing ranking。
7. **系統與整合**：地圖與通勤、社群登入、外部服務、系統狀態。
8. **意見與治理**：使用者回饋、管理操作紀錄。

深連結：`/admin.html#inventory/sources` 這類二級 hash。舊 `#members` 等對應到新頁。

## Security

- 未授權必須被擋在 API 與頁面。
- 不在畫面或前端原始碼暴露 SMTP 密碼、VAPID 私鑰、OAuth secret 或 API Key 明文。
- Audit 不記密碼與密鑰。
