# Login / 登入與註冊

覆寫範圍：`v3/public/login.html`。重設密碼見 `reset.html`，沿用同一張卡片邏輯。

## Purpose

完成登入、註冊、忘記密碼。這不是品牌 landing，沒有滿版照片或行銷大標。

## Layout

- 單張 AuthCard 置中，寬度約 `min(420px, calc(100vw - 24px))`。
- 驗證碼：圖在上、輸入與「換一張」在下；輸入列最小高度 44px，可橫向填寫。
- 主按鈕用 `--accent`。輔助連結用文字，不要做成第二個 Hero CTA。

## States

- 驗證碼錯誤、帳密錯誤、註冊成功提示維持現有文案。
- 鍵盤可 tab 完所有欄位；焦點可見。
- 375px 不得出現橫向捲動或被擠成直向細輸入條。
- 註冊分頁顯示兩個月未登入暫停爬蟲／通知、再登入不寄信，以及一年未使用刪帳仍在評估。
- 登入與註冊都把 Google／LINE／Facebook 放在分頁切換正下方、Email 表單上方（觸控 ≥ 44px），375 不捲也要看得見。後台沒開通的鈕反灰、cursor 禁用，並用文字說明「後台尚未開通」；不要整排消失讓人以為沒有社群註冊。註冊分頁先勾免責／個資才能走社群；新帳號仍須完成開通信，已開通才設 session。
